# Code of Conduct

## Our Pledge

We are committed to providing a respectful, inclusive, and harassment-free environment for everyone contributing to this project.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect different viewpoints and experience levels.
- Give constructive feedback.
- Focus discussions on the project and user outcomes.

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks.
- Publishing private information without permission.
- Trolling, insulting comments, or sustained disruption.

## Enforcement

Project maintainers may remove comments, close issues, or restrict participation for behavior that violates this code of conduct.
