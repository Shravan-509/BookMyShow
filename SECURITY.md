# Security Policy

## Supported Versions

This project is maintained as a capstone/open-source portfolio project. Security fixes should target the latest `main` branch unless a release branch is created.

## Reporting a Vulnerability

Please do not open a public issue for sensitive vulnerabilities. Instead, contact the maintainer privately through the repository owner profile or a trusted communication channel.

Include:

- Affected component or endpoint
- Steps to reproduce
- Potential impact
- Suggested remediation, if known

## Security Scope

Areas of interest include:

- JWT/session handling
- Password reset and verification flows
- Razorpay payment verification
- Authorization and role enforcement
- NoSQL injection and input validation
- Secret leakage
- CORS/cookie configuration

See [docs/SECURITY.md](docs/SECURITY.md) for the project security review.
